# Timișoara Rental Scanner & Telegram Bot 🏢🇷🇴

Автоматический мониторинг объявлений по долгосрочной аренде квартир в Тимишоаре (Румыния) с отправкой подробных карточек в Telegram.

## 🎯 Параметры поиска
- **Комнаты**: 3+ (3, 4, 5+ комнат)
- **Площадь**: от 55 м²
- **Цена**: до 800 € / месяц
- **Геолокация**: Северная и центральная часть Тимишоары (*Cetate, Take Ionescu, Circumvalațiunii, Dacia, Aradului, Lipovei, Torontalului, Bucovina, Tipografilor, Modern*)
- **Площадки**:
  1. `OLX.ro`
  2. `Storia.ro`
  3. `Imobiliare.ro`
  4. `ImoRadar24.ro`
  5. `Publi24.ro`

---

## 💎 Полный состав карточки в Telegram:
1. **Заголовок** — переведен на русский язык с ссылкой на оригинал.
2. **Цена и залог (Garanție)** — например: `800 EUR | Залог: 1 месяц`.
3. **Точная квадратура и комнатность** — например: `110 м² | 3 camere`.
4. **Этаж и тип здания** — например: `2 этаж | 🏛️ Историческое здание` или `🏢 Новостройка`.
5. **Район и адрес** — улица, номер дома, район.
6. **Название ЖК (Жилого комплекса)** — распознает комплексы (*ISHO, Denya Forest, Nord One, City of Mara, Uptown, Monarch, AFI, Vivalia, XCity Park, Paltim* и др.) либо пишет «Не указан».
7. **Паркинг** — подробный статус:
   - `✅ Да (подземный; включен в стоимость)`
   - `✅ Да (на улице / во дворе; за отдельную плату)`
   - `❌ Не указано`
8. **Комфорт**:
   - `❄️ Кондиционер`: `✅ Есть` / `Не указан`
   - `🌿 Балкон / Терраса`: `✅ Есть` / `Не указан`
9. **Условия**:
   - `💼 Комиссия`: `0% (Без комиссии)` / `50%`
10. **Метка на карте** — прямая ссылка на Google Maps с точными координатами или адресом дома.
11. **Специальные бейджи**: `👤 ОТ СОБСТВЕННИКА`, `🔥 Свой газовый котёл (Centrală proprie pe gaz)`.
12. **Контакты / Телефон** — прямой номер телефона из текста объявления.
13. **ПОЛНОЕ ОПИСАНИЕ БЕЗ ОБРЕЗАНИЯ** — переведенное на русский язык в полном объеме (без многоточий).
14. **Фотографии** — полный альбом фото высокого разрешения (до 10 шт. в альбоме).

## 🚀 Команда для запуска

```bash
source .venv/bin/activate && python main.py --run
```

* После первичного старта все текущие объявления сохраняются в базу.
* **При любых дальнейших перезапусках бота** (отключение / включение компьютера):
  Бот **НЕ будет спамить старыми объявлениями**, а сразу продолжит тихий автоматический мониторинг каждые 3 минуты и будет присылать **только новые квартиры** по мере их выхода на рынок!
